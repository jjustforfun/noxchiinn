# Аудиозаписи

Здесь должны находиться согласованные записи носителя чеченского языка.
Путь `public/audio/alphabet-a.mp3` соответствует `/audio/alphabet-a.mp3` в JSON.

Сейчас MP3-файлов нет. Не создавайте пустые файлы-заглушки.
Подробные инструкции и правила разрешений: `docs/audio.md` в исходном проекте.
Договоры, контакты дикторов и другие персональные документы сюда не помещаются.
