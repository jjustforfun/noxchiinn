# Отчёт Этапа 4

## Реализовано

- Сохранена существующая дизайн-система. Основной пейзаж, темы и игры не заменены другим интерфейсом.
- Месячный календарь на 12 месяцев назад: выбранный день, успех/попытка/сегодня, подписи для screen reader, стрелки/Home/End/PageUp/PageDown и фактические занятия.
- Текущая и лучшая серия разделены. Пропуск не удаляет рекорд и награду. Соседние даты устойчивы к DST, запись на один день впереди допустима при смене часового пояса назад.
- Экран `/#parents` со сводкой за 7/30 дней, календарём, последними раундами и спокойной рекомендацией повторения. В отдельном разделе видны все темы.
- В профиле есть календарь, лучшая серия, отдельные буквы/слова, темы и параметры звука.
- Семейная цель 12/20/32 XP сохраняется и отображается на главном экране. Она не меняет условие серии и не штрафует за пропуск.
- История ограничена 80 раундами, дневные суммы 366 датами. Незавершённые раунды не входят в процент точности. История старых занятий не выдумывается.
- Профиль v4 мигрирует v1/v2/v3. Сохраняются XP, уроки, серия, карточки и обработанные события. Импорт до 250 КБ отключает напоминания и требует нового согласия.
- Напоминания выключены по умолчанию. Есть согласие взрослого, время/дни/канал, ограничение частоты, тихие часы и немедленное отключение.
- Notification API и showNotification создают локальное системное уведомление открытой страницы. Нет автоматического permission-запроса, повторного prompt после отказа, push-подписки или отправки данных на сервер.
- Нажатие уведомления фокусирует вкладку без reload активного урока. Адрес из payload не используется.
- Отключаемые неголосовые эффекты Web Audio для ответа, пары и завершения: громкость, проверка, отмена, тайм-аут и засыпание контекста. Никакого TTS.
- Новые модули входят в app shell и прежнее Workbox-кэширование. Новые npm-зависимости для этих возможностей не добавлялись.

## Остатки Этапа 3

До изменений повторно выполнена исходная production-сборка: успешно, HTML 555.18 КБ / gzip 218.47 КБ. `.git/HEAD` по-прежнему отсутствует. В `public/icons` только SVG; PNG/Apple Touch Icon/WebP-генератор не выполнялся.

Повторная установка уже используемого Vite 7.3.5 запустила npm-аудит при установке: 136 пакетов, одна low-уязвимость. Подробный отдельный npm audit доступными инструментами не выполнялся; предупреждение не объявляется исправленным.

Эта среда не предоставляет запуск произвольных терминальных команд, Vitest, Playwright или Lighthouse. Проверяющий скрипт и GitHub Actions не считаются запущенными из-за их наличия. Сборку выполняет отдельный инструмент build_project.

## Как Закрыть Приёмку

1. Выполнить `node scripts/check.mjs --init-git`, разобрать реальные unit/type/audit результаты и low-предупреждение.
2. Выполнить `npx playwright install chromium`, `node scripts/assets.mjs`, штатную `npm run build` и `npx playwright test`.
3. Пройти успешный и неуспешный раунд, открыть календарь и историю. Проверить суммы и отсутствие двойного XP/счётчика.
4. Перенести сохранение v3: старые XP/серия должны остаться, а вымышленных подробностей быть не должно.
5. Проверить соседние дни, DST, возврат назад через местную полночь и переключение месяцев.
6. Проверить напоминание с согласием: только дневное окно, вне урока, без повторов после «Не сегодня», занятия, перезагрузки и во второй вкладке.
7. В HTTPS проверить permission default/granted/denied, установленное iOS-приложение, системный тест, отключение и нажатие уведомления при активном уроке другой вкладки.
8. Закрыть приложение и убедиться, что инструкция честно описывает отсутствие новой фоновой доставки. Это не тест «успешного background push».
9. Проверить эффекты, mute/volume, скрытие страницы, отсутствие тона поверх записи носителя и офлайн-работу.
10. Проверить 360/390/768 px, масштаб 200%, клавиатуру, screen reader, контраст и Lighthouse. Категория PWA удалена, установка/офлайн проверяются отдельно.
