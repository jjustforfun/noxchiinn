# Отчёт Этапа 6

## Ревизия Прошлых Этапов

Проведена сквозная сверка требований и текущего кода. Главный вывод: **не все требования этапов 1–5 были закрыты**. Подробная таблица по каждому этапу находится в `docs/project-review.md`, security-остатки в `docs/security-audit.md`.

Повторно подтверждена исходная сборка этапа 5. npm при повторной установке используемого Vite 7.3.5 проверил 136 пакетов и сообщил о той же одной low-уязвимости. Полный npm audit --json, Git, тестовые и браузерные команды доступными инструментами выполнить нельзя. Они не отмечены пройденными.

Исправлены конкретные дополнительные пробелы: отдельные CSP/HTTP-маршруты для всех HTML, поддержка sitemap XML и 404, повторная загрузка повреждённого кэша, сохранение более свежего in-memory прогресса после ошибки квоты. Обновлён порядок выпуска с проверкой конечных файлов.

## Реализовано

- Главный игровой экран и его визуальный язык сохранены. Ни backend, ни аналитика, ни TTS не подключались.
- Восемь видимых FAQ с самодостаточными ответами об обучении, возрасте, диаспоре, произношении, offline, приватности и добровольных занятиях.
- Публичные страницы о проекте, данных и источниках. Они не монтируют LearningApp и не читают профиль. Подготовленный HTML работает без JavaScript.
- Статический публичный снимок главной уже включён в исходный index.html. Финальный prerender из общих JSON и React-компонентов формирует тот же фактический контент без пользовательских данных.
- Уникальные title/description/OG/Twitter на каждой странице. WebApplication, Course и FAQPage основаны на реальных возможностях, без фиктивных рейтингов, адресов и автора.
- Без согласованного домена canonical и абсолютные OG URL не придумываются. Настроены origin/indexing-гейты, пустой preview sitemap и noindex.
- При согласованном домене публикуются canonical, ru/x-default hreflang, абсолютные изображения и sitemap четырёх существующих URL. Полных ce/en-переводов нет, ложные hreflang не создаются.
- Строгая CSP сохраняется: prerender выполняется до вычисления хешей, каждая HTML получает свою HTTP-политику. XML/404 и новые документы включены в контролируемый выпуск и offline-кэш.
- Шрифты вынесены из base64 HTML в локальные хешированные WOFF2 с preload и swap. Это уменьшило размер начального HTML; шрифт и дизайн остались прежними.
- Генератор изображений дополнен JPEG-превью 1200x630. Его запуск, как и PNG/WebP, по-прежнему нужен в среде с Chromium.
- `scripts/publish.mjs` объединяет prerender -> harden -> verify-release без собственной команды сборки. Vercel, Netlify и CI используют этот порядок.
- Проверяющий скрипт сверяет SRI/CSP, метатеги, h1, FAQ, локальные ссылки и JS-бюджет. Аналитика остаётся выключенной опцией и не может незаметно активироваться.

## Тесты И Проверки

`tests/seo.test.js`: 33 сценария домена, индексации, preview-гейтов, metadata, JSON-LD, соответствия FAQ, prerender без профиля, sitemap и CSP для каждого документа.

`tests/review.test.js`: четыре регрессии повторной инициализации профиля и XML MIME/SRI. Добавлены девять Playwright-сценариев: HTML до JavaScript, публичные страницы без JS, заголовки, отсутствие личных данных, FAQ/клавиатура, настоящая 404, viewport, offline и отсутствие запросов аналитики.

Все эти сценарии **подготовлены, не выданы за пройденные**. Команда scripts/verify-release.mjs создаёт фактический отчёт только при исполнении. В репозитории нет поддельного release-checks.json.

## Актуальность SEO/GEO

Проверены официальные Google Search Central JavaScript SEO и changelog. В 2026 FAQ rich result отключён в Google; JSON-LD оставлен как описание контента, а не обещание сниппета. Сохраняются стандартные SEO-практики: доступный HTML, ясные ответы, источники, корректные URL и быстрые ресурсы. Никакой гарантии цитирования ChatGPT/Perplexity, индексации или «GEO score» не заявляется.

Публичные даты, метаданные и тексты не содержат имени ребёнка, XP или истории. Для семей Франции/Европы/России/Чечни есть понятное контекстное описание, но нет вымышленных локальных офисов или организаций.

## До Приёмки

Выполнить `docs/deployment.md`: закрыть npm-аудит и реальные тесты, подготовить изображения, пересобрать, выполнить publish и Playwright, проверить HTTPS/headers/Lighthouse. Для включения индексирования нужен согласованный домен. Для релиза языка нужны проверка преподавателем и согласованные записи носителей. Следующий этап не должен стирать эти ограничения.
