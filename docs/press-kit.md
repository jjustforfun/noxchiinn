# Пресс-кит «Нохчийн Мотт»

**Обновлено:** 2026-09-15 · Статус: подготовка к релизу (не опубликовано)

## Короткое описание (для соцсетей, ≤ 200 символов)

Нохчийн Мотт — бесплатная офлайн-игра, которая помогает детям от 5 лет
учить чеченский язык: алфавит, цифры, цвета и первые слова. Без рекламы,
без сбора данных, с дружелюбным волчонком-наставником.

## Среднее описание (для магазина приложений, ~500 символов)

«Нохчийн Мотт» («Чеченский язык») — обучающая PWA-игра для детей из
чеченской диаспоры и всех, кто хочет сохранить родной язык. Ребёнок
проходит темы по порядку: алфавит → цифры → цвета → первые слова → семья,
еда, животные, тело. Мини-игры «Найди пару», «Собери слово» и «Быстрые
открытия» закрепляют лексику, а сердечки, звёзды, XP и ежедневная серия
поддерживают мотивацию. Приложение работает офлайн после первой загрузки,
хранит прогресс только на устройстве, не показывает рекламу и не собирает
персональные данные детей. Есть уголок для родителей со статистикой.

## Ключевые факты

| Параметр | Значение |
| --- | --- |
| Название | Нохчийн Мотт (Чеченский язык) |
| Аудитория | Дети от 5 лет и их близкие; чеченская диаспора |
| Платформа | PWA (браузер + установка на домашний экран), офлайн |
| Темы | 8 тем, 24 урока, 117 карточек лексики |
| Игры | Узнавание, викторина, «Найди пару», «Собери слово» |
| Мотивация | Сердечки, звёзды (1–3), XP, ежедневная серия, календарь |
| Данные | Только localStorage на устройстве; без сервера и аналитики |
| Реклама/трекинг | Нет |
| Стоимость | Бесплатно |
| Языки интерфейса | Русский (пояснения), чеченский (учебный контент) |
| Технологии | React + Vite + Tailwind, Workbox, простой JS-слой игры |

## Что честно НЕ входит в текущую версию

- **Аудио носителей языка отсутствует** (0 из 118 записей). Звуковой режим
  включится только после записи и проверки прав; TTS не используется.
- Материал помечен `native-review-needed` — нужна проверка преподавателя
  чеченского.
- Тема «Природа» обозначена как будущая и не наполнена.
- Пуш-уведомлений при закрытом приложении нет (только локальная подсказка
  в открытой игре).

## Тон и ценности

Тёплый, семейный, уважительный к языку и культуре. Игра — про сохранение
связи с корнями, а не про соревнование. Волчонок (символ Кавказа) —
дружелюбный наставник, а не строгий учитель.

## Контакт и права

Аудио носителей и лицензии оформляются отдельно (см. `docs/audio.md`).
Источники учебного контента перечислены в `data/sources.json` и на
странице `/sources.html`. Перед публичным анонсом заполните домен,
контактный e-mail и данные правообладателя.
