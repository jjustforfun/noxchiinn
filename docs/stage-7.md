### Разбор оставшейся npm-уязвимости

Единственная low-уязвимость — `esbuild` (GHSA-g7r4-m6w7-qqqr, CVSS 2.5:
чтение файлов dev-сервером esbuild только под Windows), приходившая
транзитивно через Vite 7.3.5 (пин `^0.27.0`). Закрыта закреплённым
`overrides.esbuild: "0.28.2"` в `package.json`. После этого `npm audit`
сообщает 0 уязвимостей; сборка, 337 тестов и `tsc` продолжают проходить.
Это dev-only и не влияет на production-артефакты, но остаток убран, чтобы
не блокировать приёмку.

### Генерация растровых ресурсов

Штатный `scripts/assets.mjs` рендерит иконки через Chromium из Playwright.
В этой песочнице Chromium скачать нельзя (сеть обрывает загрузку с
cdn.playwright.dev и deb.debian.org). Поэтому те же файлы созданы через
`sharp` (librsvg 2.62 + libwebp 1.6) с идентичными именами, размерами,
фоном `#eaf2dc` и параметрами (WebP q82, JPEG q87):

- `public/icons/icon-192.png`, `icon-512.png`, `apple-touch-icon.png` (180),
  `maskable-512.png`;
- `public/images/learning-landscape.webp` (~22 КБ, было 1.36 МБ PNG);
- `public/images/share.jpg` (1200×630, маскот + слоган).

Manifest переключён на PNG-иконки, в `index.html` подключён Apple Touch Icon.
Файлы визуально проверены. Если доступен Chromium, канонический путь —
`node scripts/assets.mjs`; результат эквивалентен.

## Проверка контента (без замены лингвистической рецензии)

- Подтверждено: **117 карточек** каталога + `word-nana` = **118** нужных
  записей; все `audioStatus: pending`, все темы `native-review-needed`.
- Спорные числа 16–19 (ялхитта, вуьрхӀитта, берхӀитта, ткъайоьсна) взяты из
  одного источника Govzalla, альтернативы отмечены, но не смешаны.
- Цвета: базовые прилагательные (боьмаша для коричневого, сира из
  разговорника) — задокументировано в `docs/content-review.md`.
- Игровые диграфы проверены прогоном токенизатора: `кх`, `къ`, `кӀ`, `аь`,
  `оь` не распадаются; повторяющиеся буквы (нана → н,а,н,а) остаются
  отдельными фишками. Логика data-driven из `data/alphabet.json`.
- Полный список отсутствующих записей: `docs/audio-checklist.md`.

Это техническая и источниковая сверка, **не** проверка носителем-преподавателем.
Перед релизом каждое написание, перевод, контекст, вариант числительного/цвета
и разбор слова на фишки должен утвердить преподаватель чеченского.

## Доступные UX-проверки

- Приложение поднято на dev-сервере и доступно как живой предпросмотр; можно
  вручную пройти карту тем, урок, мини-игры, профиль и родительский уголок.
- Семантический HTML, `lang="ru"`, единственный h1 на страницу, alt-тексты,
  видимый FAQ через нативные `details` — проверены в артефактах verify-release.
- Возрастные режимы (5–8 / 9+), крупные кнопки, подписи у цветов — присутствуют
  в коде и данных.

Автоматизированный обход с эмуляцией ребёнка 5 лет и подростка 12 лет
**не заменяет** реальное тестирование с детьми — оно остаётся открытым.

## Не выполнено — блокеры публичного релиза

1. **Браузерные тесты (42 сценария Playwright) и Lighthouse не запущены.**
   Chromium недоступен для скачивания в песочнице (сеть блокирует загрузку).
   `docs/release-checks.json`: `browserVerified=false`, `lighthouseVerified=false`.
   Нужен прогон в среде с браузером: `npx playwright install chromium` →
   `node scripts/assets.mjs` → `npm run build` → `node scripts/publish.mjs` →
   `npx playwright test`, затем Lighthouse на HTTPS-сборке.
2. **Аудио носителей языка — 0 из 118.** TTS не используется. Нужны записи с
   согласием, проверкой прав и произношения (см. `docs/audio.md`,
   `docs/audio-checklist.md`).
3. **Лингвистическая рецензия преподавателя** всего контента не проведена.
4. **Домен и хостинг не согласованы.** `data/site.json`: origin=null,
   indexing=false. `SITE_URL`/`SITE_INDEXING=1` задаются только после приёмки;
   примерный домен не подставлялся.
5. **Реальные устройства, скринридер, 200% масштаб, офлайн/установка/обновление
   в настоящем браузере, Safari/iOS** — не проверены.
6. **Скриншоты экранов игры для пресс-кита** не сняты (нет браузера для снимка);
   `share.jpg` и иконки — реальные и готовы.
7. Тема «Природа» не наполнена (обозначена как будущая, не имитируется).
