# Отчёт Этапа 5

## Выполнено

Проведён статический аудит по официальным OWASP Top 10:2025. Таблица всех десяти категорий, найденные дефекты, исправления и остаточные риски находятся в `docs/security-audit.md`.

Сохранены дизайн, контент и все игры. Изменения интерфейса связаны только с безопасностью: подтверждение импорта, сравнение профилей, постоянное предупреждение о записи, блокировка действий при сохранении или неизвестной схеме. Индикатор прогресса переведён на native progress для отказа от inline-стилей.

Данные ограничены по UTF-8-байтам, глубине и количеству узлов. Записи вкладок и резервирование напоминаний используют один Web Lock. Отзыв согласия повторно читается из сохранения. Активация неполного Service Worker не допускается, случайные media URL исключены из кэша. Готов генератор строгой CSP/SRI-защиты финальных артефактов.

Новые зависимости не добавлены, прямые версии закреплены точно установщиком. GitHub Actions закреплены на проверенные официальные SHA; добавлены Dependabot и отдельная проверка npm уровня low. Сервер приложения, внешний мониторинг, фоновые Push и TTS не подключены.

## Тесты

`tests/security.test.js`: лимиты JSON, опасные ключи, импорт без побочных эффектов, отказ записи/квота, будущие схемы, сравнение snapshot, Web Lock, повторное чтение согласия, CSP-хеши, контрольные суммы, ограничение потоков и worker client.

`tests/browser/security.spec.ts`: фактическое блокирование inline-script, HTTP-заголовки, подтверждение/отмена импорта, отключение импортированного согласия, повреждённые файлы, будущая схема, две вкладки, отсутствие style attributes и отсутствие случайных media в кэше.

Эти сценарии подготовлены, не объявляются пройденными. `playwright.config.ts` теперь использует scripts/serve.mjs и требует предварительно защищённой сборки. Отчёт scripts/check.mjs также включает бюджет начального JS gzip; эта команда здесь не исполнялась.

## Локальная Приёмка

1. `npm ci`.
2. `node scripts/check.mjs --init-git`. Изучить настоящий npm audit и ошибки тестов, исправить их.
3. `npx playwright install chromium` и `node scripts/assets.mjs` для иконок/WebP.
4. Штатная `npm run build`.
5. `node scripts/harden.mjs` для финальных CSP/SRI/заголовков.
6. `npx playwright test` и проверка отчётов, а не только файлов тестов.
7. Проверить production HTTPS, обновление нескольких вкладок, инвалидацию и восстановление offline. Прогнать Lighthouse и WCAG на 360/390/768 px.
