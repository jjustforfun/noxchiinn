# Отчёт Этапа 1

## Реализовано

- Рабочая основа React + Vite в существующей среде; конфигурация Vite и package.json вручную не изменялись.
- Дизайн-система, 4 экрана, карта тем, волчонок, адаптивная навигация.
- JSON Schema и 49 букв чеченского алфавита в отдельном файле, распределение по 8 урокам.
- Дополнительная интерактивная демонстрация: сопоставление букв, XP, звёзды, жизни с таймером, практика, серия и возрастные режимы.
- Валидируемый localStorage, резервная копия повреждённого сохранения, экспорт и импорт.
- Один аудиомодуль; отсутствующие записи явно обозначены. TTS и нелицензированное аудио не используются.
- Manifest, SVG-иконки 192/512/maskable, Workbox app shell, стратегии для будущих медиа и данных, offline fallback.
- Русскоязычные метатеги, базовый WebApplication JSON-LD, инструкции новичку, .gitignore и lockfile.
- Набор Vitest для логики, данных, аудиозаглушек и ограничения адресов Service Worker.

## Уточнение Про Lighthouse

Категория PWA удалена начиная с Lighthouse 12. Поэтому обещать «Lighthouse PWA score = 100» в современных версиях некорректно. Performance, Accessibility, Best Practices и SEO измеряются Lighthouse, а установка, manifest, offline и обновления проверяются отдельно.

Источник: https://github.com/GoogleChrome/lighthouse/releases/tag/v12.0.0

## Ручной Прогон

1. Запустить production preview или открыть HTTPS-развёртывание.
2. На чистом профиле убедиться: 0 XP, 5 жизней, 0 дней, 0 пройденных уроков.
3. Пройти первый урок без ошибок: получить 20 XP в режиме 5-8, 3 звезды, серию 1, доступ ко второму уроку.
4. Перезагрузить страницу: результат должен остаться.
5. Дать неверный ответ в уроке: одна жизнь уходит; верный вариант и пояснение видны.
6. Пройти свободную тренировку: ошибок можно не бояться; успешный раунд возвращает жизнь, но не открывает следующий урок.
7. Нажать кнопку аудио: появляется честное пояснение об ожидающей записи.
8. Изменить прозвище, возраст и аватар, проверить после перезагрузки.
9. Экспортировать сохранение, импортировать его обратно; испорченный файл не должен менять текущий прогресс.
10. Дождаться подтверждения подготовки офлайн, включить Offline в DevTools и перезагрузить. Проверить урок и сохранение.
11. Пройти страницы при 360, 390 и 768 px, проверить горизонтальную прокрутку и наложения.
12. Пройти кнопки с Tab, проверить Escape и возврат фокуса из диалога, затем screen reader и 200% масштаб.
13. Выполнить `npx vitest run --config vitest.config.js`, `npx tsc --noEmit`, `npm audit`; приложить реальные результаты.
14. Прогнать Lighthouse и сохранить отчёты. Проверить production CSP, MIME-типы и HTTPS через DevTools.
